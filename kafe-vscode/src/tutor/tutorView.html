Your first KAFE program
  1. Open a workspace folder in VS Code.
  2. Create and save a .kf file in that folder.
  3. When you choose to run it, use KAFE: Run File.
  4. Read the output and enter any input in the native KAFE Run terminal.

Running a program requires a trusted workspace and the KAFE runtime. Tutor conversation has separate setup.
