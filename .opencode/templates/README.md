# Templates

Reusable project templates for the KAFE engineering system. This directory indexes the canonical templates; each record template lives next to its records.

## Workflow Templates

| Template | Location |
|----------|----------|
| Impact Analysis | `.opencode/templates/impact-analysis.md` |
| Definition of Done checklist | `.opencode/templates/dod-checklist.md` |
| Benchmark | `.opencode/templates/benchmark-template.md` |
| Session Recovery | `.opencode/templates/session-recovery.md` |

## Record Templates

| Template | Location |
|----------|----------|
| Concept record | `.opencode/knowledge/concepts/concept-template.md` |
| RFC | `.opencode/rfc/template.md` |
| ADR | `.opencode/adr/template.md` |
| History record | `.opencode/history/template.md` |
| Benchmark record | `.opencode/benchmarks/template.md` |

Use the matching template when creating a new concept, RFC, ADR, history record, or benchmark. Keep `.opencode/templates/benchmark-template.md` in sync with `.opencode/benchmarks/template.md`.
