# Session Recovery

Reusable format for reconstructing project state (see `.opencode/knowledge/engineering.md` — Session Recovery Process and `.opencode/commands/resume.md`). Fill after reading the layers in order.

## Layers Read

1. **Knowledge** — `.opencode/knowledge/`: <what KAFE is and how processes run>
2. **Memory** — `.opencode/memory/`: <current state, active work, debt, issues>
3. **History** — `.opencode/history/`: <recent significant events with dates>
4. **Progress** — `.opencode/progress/`: <roadmap, backlog, milestones, current tracking, session-log (recent closed sessions)>

## Report

- **Current project status**: <what KAFE is, latest milestones, system health>
- **Active work**: <items being worked on>
- **Pending work**: <backlog and open roadmap items>
- **Recent history**: <relevant history records>
- **Blockers**: <anything blocking work>
- **Recommended next steps**: <prioritized proposal>

## Rule

Do not propose changes until the state is fully reconstructed and reported.
