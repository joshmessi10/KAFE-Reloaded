# Concept Template

New concepts introduced into KAFE are documented under `.opencode/knowledge/concepts/` as `<concept-name>.md`.

## Name

The concept name.

## Category

Language feature, ML algorithm, DL component, library utility, engineering practice, etc.

## Description

What it is and how it works. Include advantages and limitations when relevant.

## Motivation

Why this concept exists and why it was introduced into KAFE.

## Dependencies

- Other KAFE features, libraries, or modules this concept depends on.

## Related Concepts

- Related concepts in the knowledge graph.

## Usage Examples

- Usage examples (`.kf` snippets) demonstrating the concept.

## Implementation Location

- File and module paths under `src/` where this concept is implemented.

## Public API

- KAFE syntax, functions, factories, and methods exposed to users.

## References

- Reference materials: docs, RFCs, ADRs, papers, or external resources that informed the concept.
