# Gaussian Mixture Model (GMM)

## Mathematical Foundation

A probabilistic model that assumes the data were generated by a mixture of Gaussian distributions.

### Model

$$P(\mathbf{x}) = \sum_{k=1}^{K} \pi_k \cdot \mathcal{N}(\mathbf{x} | \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$$

where:
- $\pi_k$ is the weight of component $k$ ($\sum \pi_k = 1$).
- $\boldsymbol{\mu}_k$ is the mean of component $k$.
- $\boldsymbol{\Sigma}_k$ is the covariance of component $k$.
- $\mathcal{N}(\mathbf{x} | \boldsymbol{\mu}, \boldsymbol{\Sigma})$ is a multivariate Gaussian.

### EM Algorithm (Expectation-Maximization)

**E-step:** Calculate responsibilities.
$$\gamma(z_k) = \frac{\pi_k \cdot \mathcal{N}(\mathbf{x}_n | \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)}{\sum_j \pi_j \cdot \mathcal{N}(\mathbf{x}_n | \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)}$$

**M-step:** Update parameters.
$$\boldsymbol{\mu}_k = \frac{\sum_n \gamma(z_{kn}) \cdot \mathbf{x}_n}{N_k}$$
$$\boldsymbol{\Sigma}_k = \frac{\sum_n \gamma(z_{kn}) \cdot (\mathbf{x}_n - \boldsymbol{\mu}_k)(\mathbf{x}_n - \boldsymbol{\mu}_k)^T}{N_k}$$
$$\pi_k = \frac{N_k}{N}$$

## Computational Complexity

| Operation | Time Complexity | Space Complexity |
|-----------|---------------------|---------------------|
| fit (EM) | $O(T \cdot n \cdot K \cdot d)$ | $O(n \cdot K)$ |
| predict | $O(n \cdot K \cdot d)$ | $O(n)$ |

Here, $T$ is the number of iterations, $n$ is the number of samples, $K$ is the number of components, and $d$ is the number of features.

## Advantages

1. **Soft clustering** — estimates membership probabilities rather than only assigning labels.
2. **Elliptical shapes** — can capture elliptical clusters, unlike the spherical clusters assumed by K-Means.
3. **Generative model** — can generate new points.
4. **Statistically grounded** — based on a well-established statistical framework.

## Limitations

1. **Sensitive to initialization** — it may converge to a local optimum.
2. **Assumes Gaussian distributions** — it may perform poorly when this assumption is violated.
3. **Sensitive to outliers** — outliers can distort the means.
4. **Requires the number of components** — specify $K$ or use AIC/BIC to select it.

## Comparison with K-Means

| Aspect | K-Means | GMM |
|---------|---------|-----|
| Type | Hard clustering | Soft clustering |
| Cluster shape | Spherical | Elliptical |
| Model | Distance to centroids | Probabilistic |
| Output | Labels | Probabilities |

## Selecting the Number of Components

Use AIC or BIC to select $K$:
- **AIC**: $2p - 2\ln(\hat{L})$ (lower is better).
- **BIC**: $p\ln(n) - 2\ln(\hat{L})$ (lower is better; it penalizes complex models more strongly).

## KAFE Implementation

The KAFE implementation (`GaussianMixture.py`) supports:

- **Diagonal covariance** — each feature has its own variance, independent of the others.
- **Random initialization** — randomly selected points serve as initial means.
- **Convergence** — based on the change in log-likelihood with a configurable tolerance.
- **AIC/BIC** — information criteria for selecting the number of components.

### Main Methods

| Method | Description |
|--------|-------------|
| `fit(X)` | Fits the model with EM. |
| `predict(X)` | Assigns each point to its most likely component. |
| `predict_proba(X)` | Returns component responsibilities (probabilities). |
| `fit_predict(X)` | Fits the model and returns labels. |
| `score(X)` | Returns the negative log-likelihood. |
| `aic(X)` | Computes the Akaike information criterion. |
| `bic(X)` | Computes the Bayesian information criterion. |

## When to Use

- Clustering data with elliptical shapes.
- When membership probabilities are useful.
- Data that plausibly follow Gaussian distributions.
- When a generative model is needed.

## When NOT to Use

- Clusters with arbitrary shapes (consider DBSCAN).
- Data with many outliers that can distort the means.
- Categorical data (GMM assumes continuous features).
