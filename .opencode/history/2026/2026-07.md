# History Record — July 2026

This file consolidates all significant project events for July 2026.

---

## 2026-07-28: KafeMACHINE Core Implementation

### BaseMachine Implementation

- **Summary**: Implemented BaseMachine, the abstract base class for all KafeMACHINE models. Provides the common API contract (fit/predict/transform), input validation, and fitted-state guards. Supports both List and PARDOS DataFrame inputs via `_unwrap_data()`.
- **Impacted Modules**: `src/lib/KafeMACHINE/BaseMachine.py` (new)
- **Related Tests**: Unit tests for fit/predict/transform contract

### LinearRegression Implementation

- **Summary**: Implemented LinearRegression from scratch using the Ordinary Least Squares (OLS) normal equation: $\hat{\beta} = (X^T X)^{-1} X^T y$. Supports single-feature and multi-feature regression. Factory function `machine.linear_regression()` added.
- **Impacted Modules**: `src/lib/KafeMACHINE/LinearRegression.py` (new), `src/lib/KafeMACHINE/funciones.py`
- **Related Tests**: `tests/KafeMACHINE/linear_models/test_linear_regression*.kf`

### LogisticRegression Implementation

- **Summary**: Implemented LogisticRegression from scratch using gradient descent with sigmoid activation. Supports binary classification (y ∈ {0, 1}). Factory function `machine.logistic_regression(lr, iter)` added.
- **Impacted Modules**: `src/lib/KafeMACHINE/LogisticRegression.py` (new), `src/lib/KafeMACHINE/funciones.py`
- **Related Tests**: `tests/KafeMACHINE/linear_models/test_logistic_regression*.kf`

### KNN Implementation

- **Summary**: Implemented K-Nearest Neighbors classifier from scratch using Euclidean distance. Supports k-nearest neighbor voting, predict_proba, and multi-class classification. Factory function `machine.knn(k)` added.
- **Impacted Modules**: `src/lib/KafeMACHINE/KNN.py` (new), `src/lib/KafeMACHINE/funciones.py`
- **Related Tests**: `tests/KafeMACHINE/neighbors/test_knn_*.kf`

### Classification Metrics Implementation

- **Summary**: Implemented classification metrics from scratch: accuracy_score, precision_score, recall_score, f1_score, confusion_matrix, classification_report. All use macro averaging for multi-class support.
- **Impacted Modules**: `src/lib/KafeMACHINE/metrics.py` (new)
- **Related Tests**: `tests/KafeMACHINE/metrics_classification/test_*.kf`

### Regression Metrics Implementation

- **Summary**: Implemented regression metrics from scratch: mean_squared_error, mean_absolute_error, root_mean_squared_error, r2_score, max_error, median_absolute_error, mean_absolute_percentage_error, explained_variance_score.
- **Impacted Modules**: `src/lib/KafeMACHINE/metrics.py` (new)
- **Related Tests**: `tests/KafeMACHINE/metrics_regression/test_*.kf`

### Preprocessing Implementation

- **Summary**: Implemented preprocessing utilities from scratch: StandardScaler (Z-score normalization), MinMaxScaler (min-max scaling), SimpleImputer (missing value imputation), LabelEncoder (categorical encoding), OneHotEncoder (one-hot encoding).
- **Impacted Modules**: `src/lib/KafeMACHINE/StandardScaler.py`, `MinMaxScaler.py`, `SimpleImputer.py`, `LabelEncoder.py`, `OneHotEncoder.py` (all new)
- **Related Tests**: `tests/KafeMACHINE/preprocessing/test_*.kf`

### KafeMACHINE Library Registration

- **Summary**: Registered all ML models, preprocessing, and metrics in the `machine` library. Updated `EvalVisitorPrimitivo` to support the `machine` import. Factory functions follow scikit-learn-style API pattern.
- **Impacted Modules**: `src/lib/KafeMACHINE/funciones.py`, `src/lib/KafeMACHINE/__init__.py`, `src/EvalVisitorPrimitivo.py`
