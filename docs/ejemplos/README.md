# KAFE examples

Choose a collection from the navigation:

- [Feature examples](../examples/hello-world.kf) for language basics.
- [MACHINE examples](machine-kaggle.md), organized by algorithm and showing the dataset used by each method.
- [Gesha examples](gesha-examples.md), organized by neural network architecture.

The `.kf` files in this directory are complete runnable KAFE programs. Run one from the repository root with `python src/Kafe.py docs/ejemplos/<file>.kf`. Kaggle-based examples need a download on first use. Small demonstration runs show the API and workflow; they are not performance benchmarks.
