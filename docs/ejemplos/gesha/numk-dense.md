# NUMK and dense classifier

**Data:** Three generated numeric vectors  
**Program:** [`gesha-numk.kf`](../gesha-numk.kf)

## What the program teaches

Create ordinary KAFE lists through `numk.tensor`, fit a two-layer dense classifier and inspect its probability predictions. The final batch contains one sample, illustrating that a short last batch is accepted.

## Reading the code

Open the [complete KAFE source](../gesha-numk.kf) and follow its imports, input preparation, model construction and output. The linked file is the program to copy or run when you choose to try it; this page is a guide to its purpose.
