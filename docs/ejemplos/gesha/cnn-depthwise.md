# Depthwise CNN block

**Data:** One generated 4 × 4 image  
**Program:** [`gesha-cnn-avanzada.kf`](../gesha-cnn-avanzada.kf)

## What the program teaches

Pass a channel-first image through depthwise convolution, batch normalization, global average pooling and a softmax Dense layer. This example demonstrates forward prediction only; the layers start with initialized weights and are not fitted.

## Reading the code

Open the [complete KAFE source](../gesha-cnn-avanzada.kf) and follow its imports, input preparation, model construction and output. The linked file is the program to copy or run when you choose to try it; this page is a guide to its purpose.
