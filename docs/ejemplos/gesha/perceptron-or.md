# Single perceptron: OR

**Dataset:** Truth table (generated in code)  
**Architecture:** 2 → 1  
**Task:** Binary classification

## Why this architecture?

OR is also linearly separable, so a single sigmoid unit is sufficient.

Check all four binary inputs and compare expected and predicted labels.
