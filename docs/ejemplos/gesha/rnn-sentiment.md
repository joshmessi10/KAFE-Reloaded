# Embedding and RNN: sentiment

**Data:** Kaggle Yelp labeled sentences  
**Program:** [`ejemplo-rnn2-sentimiento.kf`](../ejemplo-rnn2-sentimiento.kf)

## What the program teaches

Load labeled text, make a stratified split, fit the tokenizer on training sentences only, then train an embedding plus recurrent classifier. Inspect test accuracy, the confusion matrix and predictions on new phrases. This is a small educational sample, not a reliable sentiment service.

## Reading the code

Open the [complete KAFE source](../ejemplo-rnn2-sentimiento.kf) and follow its imports, input preparation, model construction and output. The linked file is the program to copy or run when you choose to try it; this page is a guide to its purpose.
