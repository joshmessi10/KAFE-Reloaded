## La idea en una frase

Machine Learning es enseñarle a la computadora con ejemplos en lugar de escribirle cada regla.

## Una comparación de la vida diaria

Cuando eras pequeño no te dieron una regla para reconocer perros: viste **muchos perros** y aprendiste solo. Un modelo de Machine Learning hace lo mismo con los datos.

## Lo que vas a aprender aquí

- Qué es un dato, una característica y una etiqueta.
- Diferencia entre predecir un número (regresión) y una categoría (clasificación).
- Por qué separamos datos para entrenar y datos para probar.
- Cómo saber si un modelo es bueno (métricas).
