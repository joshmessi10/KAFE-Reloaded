## The idea in one sentence

Programming means giving the computer a list of instructions, in order, so it does something for you.

## An everyday comparison

It is like writing a **cooking recipe**: if the steps are clear and in the right order, anyone (even a computer!) can make the dish.

## What you will learn here

- What a program is and what a programming language is.
- What KAFE does when you run a `.kf` file.
- How to write and run your first instruction with `show`.
