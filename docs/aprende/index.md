# Aprende

Esta sección es para ti si **nunca has programado** o si quieres entender las ideas antes de ver el código. Cada lección explica un concepto con una comparación de la vida diaria, un dibujo y un ejemplo pequeño de KAFE que puedes ejecutar.

## Lecciones

Léelas en orden: cada una usa lo que aprendiste en la anterior.

1. **[¿Qué es programar?](programar.md)**: Programar es darle a la computadora una lista de instrucciones, en orden, para que haga algo por ti.
2. **[Variables y tipos](variables.md)**: Una variable es un nombre que guarda un valor para usarlo después.
3. **[Funciones](funciones.md)**: Una función es un pequeño programa con nombre que recibe datos, hace algo con ellos y devuelve un resultado.
4. **[¿Qué es aprender de datos?](aprender-de-datos.md)**: Machine Learning es enseñarle a la computadora con ejemplos en lugar de escribirle cada regla.
5. **[¿Qué es una neurona?](neuronas.md)**: Una neurona artificial es una pequeña calculadora que recibe números, les da una importancia (pesos) y decide cuánto se "enciende".

!!! tip "¿Y después?"
    Después de esta sección, sigue con el [Tutorial](../getting-started/installation.md) para instalar KAFE y escribir tus propios programas.
