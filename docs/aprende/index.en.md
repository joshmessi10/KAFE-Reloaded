# Learn

This section is for you if you **have never programmed** or want to understand the ideas before seeing code. Each lesson explains one concept with an everyday comparison, a drawing and a small KAFE example you can run.

## Lessons

Read them in order: each one uses what you learned in the previous one.

1. **[What is programming?](programar.md)**: Programming means giving the computer a list of instructions, in order, so it does something for you.
2. **[Variables and types](variables.md)**: A variable is a name that stores a value so you can use it later.
3. **[Functions](funciones.md)**: A function is a small named program that takes data, does something with it and gives back a result.
4. **[What is learning from data?](aprender-de-datos.md)**: Machine Learning means teaching the computer with examples instead of writing every rule.
5. **[What is a neuron?](neuronas.md)**: An artificial neuron is a tiny calculator that takes numbers, gives each one an importance (weights) and decides how much it "lights up".
