## The idea in one sentence

Machine Learning means teaching the computer with examples instead of writing every rule.

## An everyday comparison

When you were little nobody gave you a rule to recognize dogs: you saw **many dogs** and learned by yourself. A Machine Learning model does the same with data.

## What you will learn here

- What a data point, a feature and a label are.
- The difference between predicting a number (regression) and a category (classification).
- Why we split data into training data and test data.
- How to know if a model is good (metrics).
