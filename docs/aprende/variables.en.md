## The idea in one sentence

A variable is a name that stores a value so you can use it later.

## An everyday comparison

Imagine **labeled boxes**: in the `age` box you keep a number and in the `name` box you keep some text. The **type** says what can go in each box: you don't put shoes in the egg carton.

## What you will learn here
